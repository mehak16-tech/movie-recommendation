# Movie Recommendation System

## Project Overview
A content-based movie recommendation system that uses
K-Nearest Neighbors (KNN) to recommend movies with
similar genres.

## Objectives
- Explore content-based recommendation.
- Represent movie genres as numerical features.
- Use KNN to find similar movies.
- Return a ranked list of recommended movies.

## Technology Stack
- Python
- pandas
- NumPy
- scikit-learn
- Jupyter Notebook
- Git and GitHub
